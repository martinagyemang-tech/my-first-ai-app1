# Level 1: the app-building stage

CloudWithShad / Get Skills Network

Use the notebooks for foundations, then apply them in real project files. Plan **10 meetings of two hours**, plus 1-2 hours of independent practice between meetings. These are suggested teaching allocations, not course dates.

| Meeting | Build | Acceptance milestone | Between meetings |
|---|---|---|---|
| 1 | Notebook-to-script bridge and Market Assistant | Environment works; function validates quantity; commit pushed | Add one product and explain an error |
| 2 | Terminal AI assistant | Exact quote displayed; one AI call explained; bad input handled | Change instructions and compare outputs |
| 3 | First Streamlit app | Form collects inputs; one submit produces one result | Improve labels and empty-input feedback |
| 4 | Chatbot memory | Follow-up uses history; reset works | Explain list-of-dictionaries and reruns |
| 5 | Persona controls and first deployment | Live basic app tested by a classmate | Form groups of three; submit one-sentence problem |
| 6 | Sales dashboard | CSV validated; totals and chart independently checked | Try malformed data and explain the error |
| 7 | Bounded data Q&A | Explain what facts AI receives and what it cannot know | Add an unsupported-question example |
| 8 | Capstone skeleton and collaboration | One complete input-to-output workflow; reviewed PR | Complete assigned feature and review teammate's PR |
| 9 | Build clinic, testing and deployment | Scope finished, acceptance checklist completed | Rehearse demo; finish README and video |
| 10 | Demonstrations and reflection | Each member explains contribution and one debugging lesson | Record next improvement |

## Live-session rhythm

10 min recap; 15 min explain and predict; 40 min guided build; 10 min break; 30 min student variation/debugging; 15 min checkpoint and Git commit. Adjust to learner progress. If local setup takes longer, finish the non-AI script and move API work to Meeting 2 as planned.

## Group capstone

Guided apps are individual. Form groups around Meeting 5; plan early and build mainly in Meetings 8-9. Each member implements a feature, opens a pull request, reviews someone else's work and explains their decisions. Rotate responsibilities. See capstone/README.md for the 60% team / 40% individual rubric.

Seven minutes per group can work: about two minutes per member plus transitions. Ten groups require 70 minutes before feedback. Split Demo Day into another meeting if the group count requires it.

## Student outcome

A small useful app, a live URL, a readable GitHub repository, a demonstration and the confidence to explain how the input, Python functions, AI request and output connect. Finish one workflow before adding extra features.
